# Simple GIF Maker

Official Windows releases of Simple GIF Maker: turn a video clip into a GIF, choose a segment, crop the frame, and adjust resolution, frame rate, and compression.

## Download

[Download the latest release](https://github.com/Svekolsky/SimpleGIF-Releases/releases/latest).

- **Installer** (`SimpleGifMakerSetup-*.exe`): installs the application and offers the **Open in Simple GIF Maker** video context-menu command, enabled by default.
- **Portable** (`SimpleGIF-*-Portable.exe`): run directly without installation or Python. Explorer integration is provided by the installer.
- **SHA256SUMS.txt**: checksums for the release downloads.

Windows 10/11, 64-bit. On Windows 11, the context-menu command may appear under **Show more options**.

## Privacy

Video processing runs locally. Checking for updates contacts this repository on GitHub only when requested. No ads or telemetry.
